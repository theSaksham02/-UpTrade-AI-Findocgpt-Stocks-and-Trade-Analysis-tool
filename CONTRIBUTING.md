# Contributing to UpTrade AI

Thank you for your interest in contributing to UpTrade AI! We welcome contributions from the community to help make financial intelligence accessible to everyone.

## Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally:
    ```bash
    git clone https://github.com/your-username/uptrade-ai.git
    cd uptrade-ai
    ```
3.  **Create a new branch** for your feature or fix:
    ```bash
    git checkout -b feature/amazing-feature
    ```

## Development Setup

### Backend
1.  Navigate to `backend/`
2.  Create virtual environment: `python -m venv venv` and activate it.
3.  Install dependencies: `pip install -r requirements.txt`
4.  Run server: `uvicorn app.main:app --reload`

### Frontend
1.  Navigate to `frontend/uptrade-website/`
2.  Install dependencies: `npm install`
3.  Run dev server: `npm run dev`

## Pull Request Process

1.  Ensure your code follows the existing style conventions.
2.  Update documentation if necessary.
3.  Submit a Pull Request to the `main` branch.
4.  Provide a clear description of your changes.

## Reporting Issues

If you find a bug or have a feature request, please open an issue in the repository with details.

We look forward to your contributions! 🚀
